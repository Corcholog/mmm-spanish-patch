## 5. Formatting hazards
- **Executable strings (O1_exe.txt):** X001/X003/X005 `。` (each `\k⏎`) end a sentence after a card name the game draws (practice games of blocks A/B/C): write `.`. X002/X004/X006 (practice games) and X007 (final vs Ryo) are the menu option **降りる** next to 勝負する (0928, 1426, 1905, 3009): write **"Retirarme"** to match "Jugármela" (as in O0).
- **Sentences joined across a jump (12 joins, 3 groups):** each lead is one interjection that runs into the same card line, so the shared line starts in **lowercase** ("la carta de Reu es", as in O0:5786):
